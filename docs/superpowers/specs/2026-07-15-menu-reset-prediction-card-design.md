# 菜单栏重置预测卡片设计

## 目标

把菜单栏弹窗顶部的重置状态从弱提示升级为第一视觉层级，同时消除预测来源在顶部与操作列表中的重复入口。设计采用已确认的“时间主角”方案，并使用同心圆雷达图标。

## 信息层级

顶部预测卡片固定包含：

1. 同心圆雷达图标；正常监控状态使用蓝色，检测到重置时仅增加红色状态提示，不把整张卡片改成警报色。
2. 标题与状态胶囊：正常显示“下次重置预测 / 监控中”，活跃窗口显示“即将重置”。
3. 有预测时间时，以日期、超大时间和倒计时为主要内容；没有活跃窗口时显示清晰的等待状态。
4. 卡片内提供可点击的预测来源标签和外链图标，打开当前 forecast 的来源 URL。

Token 统计仍紧随预测卡片。操作列表删除“打开预测来源”，保留以下顺序：

1. 打开仪表盘，Command-D
2. 立即检查，Command-R
3. 设置…，Command-,
4. 退出，Command-Q

## 视觉规则

- 卡片使用系统自适应的浅蓝 tint、细边框和连续圆角，不硬编码白色背景。
- 时间使用圆角、等宽数字，成为第一视觉焦点。
- 来源标签拥有独立的圆角 hover 背景，明确表达可点击性。
- 雷达图标由 SwiftUI 基础形状绘制，不引入位图资源；包含三层同心圆、中心点与斜向扫描线。
- 弹窗继续保持 300pt 宽度，内容必须在中英文下单行或自然收缩，不扩大菜单宽度。
- 红色只用于活跃重置提示，日常监控状态保持蓝色。

## 行为与边界

- 来源入口仍打开 `forecast.sourceURL`，仅改变入口位置。
- `predictedAt` 存在时显示本地化日期、时间和每分钟更新的倒计时。
- `predictedAt` 不存在时显示“暂无活跃的官方窗口”，并保留来源入口与监控状态。
- 刷新、dashboard、设置、退出和快捷键行为保持不变。
- 不修改 forecast 数据源、token 聚合、通知策略或应用窗口结构。

## 验证

- 测试约束菜单 action 只包含 dashboard、refresh、settings、quit。
- SwiftPM 全量测试与 debug build 通过。
- 人工验证中英文、Light/Dark Mode、来源点击、快捷键、刷新 loading 状态和 300pt 宽度下的布局。
