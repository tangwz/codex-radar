# 菜单栏 Dark Mode 设计

## 目标

将菜单栏弹窗的 Dark Mode 调整为已确认的方案 1：以石墨灰为整体背景，以高饱和 Codex 蓝突出重置预测主卡。Light Mode 保持现状，信息架构、交互和业务状态均不改变。

## 视觉层级

### 外层容器

- Dark Mode 使用接近 `#171B22` 的石墨灰基底，并保留轻微的系统材质感。
- 外框与分割线使用低对比度冷灰，避免现有界面整片深蓝导致卡片层级消失。
- 不增加纹理、噪点或强烈外发光。

### 重置预测主卡

- 主卡是唯一的大面积高饱和区域，使用从深钴蓝到 Codex 蓝的克制渐变。
- 卡片标题、主要预测内容和操作图标使用白色；次级说明使用带蓝调的浅灰白。
- 雷达 Logo 保持现有结构，Dark Mode 中改为亮蓝轮廓和柔和蓝色底光。
- 状态徽标使用更亮的蓝色胶囊；当重置即将发生时，继续使用现有红色警示语义。
- 来源 Chip 使用半透明深蓝底，保持可点击状态和 hover 反馈。
- 卡片只使用轻微内高光、细描边和短距离阴影，不做霓虹效果。

### Token 统计卡

- 两张统计卡使用比外层容器略亮的深石墨表面。
- 数值使用高对比度白色，标题使用冷灰色。
- 卡片边界以微弱描边和内高光区分，不使用蓝色大色块，确保视觉焦点仍在预测主卡。

### 操作区域

- 四个操作入口保持现有顺序、图标、快捷键和行高。
- 操作区域形成一个低对比度的深色 inset group，行之间使用极细分割线。
- hover 时只提高所在行的表面亮度；不使用独立按钮阴影。
- 主文字与图标使用高对比度白色，快捷键使用较暗冷灰色。

## 主题边界

- 新增菜单栏专用的语义主题值，根据 `ColorScheme` 解析颜色、渐变、描边和阴影。
- Dark Mode 使用本设计；Light Mode 返回当前的系统自适应样式，避免本次修改意外改变已经确认的浅色界面。
- 主题只服务 `MenuBarView` 及其内部组件，不扩散到仪表盘或设置窗口。
- 继续使用 SwiftUI 原生视图与 `MenuBarExtra`，不引入 AppKit 状态项定制。

## 状态与交互

- 无官方窗口、有预测时间、刷新中和重置警示四种状态继续复用现有数据流。
- 红点提示、系统通知、预测来源链接、键盘快捷键和 hover 行为均保持不变。
- Dark Mode 切换只影响渲染，不触发数据刷新或状态重建。

## 可访问性

- 主要文字与关键数值相对背景保持清晰的高对比度。
- 次级文字不低于可读阈值，避免方案图中灰字过暗的问题。
- 颜色不作为重置警示的唯一表达方式，继续保留状态文案和红点。
- Reduce Transparency 开启时仍需保有清晰的卡片边界与层级。

## 验证

- 使用测试先定义 Dark Mode 选择新主题、Light Mode 保持旧主题的行为。
- 执行完整 SwiftPM 构建与测试。
- 在 macOS Light、Dark 两种外观下检查菜单栏弹窗。
- 人工覆盖无预测、有效预测、刷新中和红色重置警示状态。
- 检查中英文、hover、快捷键、来源链接和 Reduce Transparency 下的可读性。

## 非目标

- 不修改菜单栏 Icon、应用 Icon 或仪表盘外观。
- 不调整菜单栏宽度、组件顺序、文案或业务逻辑。
- 不为 Light Mode 做额外重设计。
