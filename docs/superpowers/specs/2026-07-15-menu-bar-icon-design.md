# 菜单栏图标设计

## 目标

将菜单栏中的 `scope` 系统图标替换为与应用图标一致的蓝色雷达 Logo，并针对菜单栏的小尺寸显示单独优化。图标主体需要尽量填满资源画布，避免直接缩放应用图标带来的白边或明显空隙。

## 设计

- 新增专用的 `MenuBarIcon` 图片资源，不复用带有 macOS 应用图标安全边距的 `AppIcon.png`。
- 保留蓝色玻璃质感、白色同心雷达环、中心圆点和右上扫描线，确保与应用图标属于同一视觉系统。
- 裁切资源外围无效区域，让蓝色图标主体贴近画布边界；最终在 SwiftUI 中以固定菜单栏尺寸显示，避免二次缩放产生额外间距。
- 使用原始彩色渲染模式，不把资源转为单色 template image。
- 保留现有右上角红色重置提示点，并让提示点覆盖在 Logo 上方，不改变已有提醒逻辑与无障碍标签。

## 影响范围

- `Sources/CodexRadar/Resources/`：增加菜单栏专用图片资源。
- `Sources/CodexRadar/Views/MenuBarView.swift`：让 `MenuBarLabel` 使用新资源，保留现有红点和无障碍语义。
- `Tests/CodexRadarTests/`：增加对菜单栏图标资源约定的测试，防止回退到系统图标或错误渲染模式。

## 验证

- 先添加失败测试，证明当前菜单栏仍使用 `scope`。
- 完成实现后执行 SwiftPM 测试与构建。
- 重新生成并启动本地 `.app`，确认资源已进入应用包。
- 在 macOS 菜单栏进行人工检查：图标主体铺满、蓝色 Logo 清晰、浅色和深色外观可辨识、红点显示位置正常。

## 非目标

- 不调整应用图标本身。
- 不改变重置预测、通知或菜单内容逻辑。
- 不引入 AppKit `NSStatusItem` 定制；当前 SwiftUI `MenuBarExtra` 足以满足需求。
